Stage 5

Evaluated on a live request

gateway memory only< 1 ms
  • The gateway sends OPA only types and positions, never the text itself.
  • OPA returns which statement applies, what to do, and whether it is in monitor or enforce mode.
// input sent to OPA
{
  "request_id": "req_7Hk2",
  "app": { "id": "sales-copilot", "approved_for": [] },
  "destination": { "provider": "openai", "hosting": "external" },
  "findings": [
    { "id": "f1", "type": "pii.email", "message": 1, "start": 9,  "end": 29 },
    { "id": "f2", "type": "pii.phone", "message": 1, "start": 38, "end": 54 }
  ]
}

// result from OPA
{
  "policy_id": "POL-AI-003",
  "policy_version": "2.1",
